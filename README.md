# Adhik Office Wale

A fun static playlist website for Adhik Office Wale.

## GitHub Pages

1. Push these files to the `main` branch.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.

Your site should then be available at:

https://skshrikant24.github.io/officeWale/

## Music note

This project does not host copyrighted song audio. Song rows open YouTube search results for the selected track.
